# 🛡️ Cybersecurity Internship – InternSpark

This repository contains all the tasks, reports, screenshots, and deliverables completed during my **Cybersecurity Internship at InternSpark**. Throughout this internship, I gained hands-on experience with fundamental cybersecurity concepts, security tools, and incident response practices.

## 📌 Internship Tasks Completed

### ✅ Task 1: Information Gathering & Reconnaissance

* Performed domain and network reconnaissance.
* Used OSINT and scanning techniques to collect information.
* Documented findings and observations.

### ✅ Task 2: Web Application Security Basics

* Tested a demo web application for common vulnerabilities.
* Identified and demonstrated **Cross-Site Scripting (XSS)** and **SQL Injection** in a safe environment.
* Used **Burp Suite** to intercept and analyze HTTP requests.

### ✅ Task 3: Network Traffic Analysis

* Captured and analyzed network packets using **Wireshark**.
* Examined **HTTP, DNS, and TCP handshake** traffic.
* Identified suspicious or unusual packet behavior.
* Prepared a packet analysis report with screenshots.

### ✅ Task 4: Incident Response Simulation

* Investigated suspicious log activities.
* Identified potential **Indicators of Compromise (IOCs)**.
* Documented incident response procedures, containment actions, and recommendations.
* Created a professional incident report.

## 📚 Skills Gained

## 🎯 Outcome

This internship provided practical exposure to real-world cybersecurity concepts and strengthened my analytical, problem-solving, and reporting skills. It helped me build a strong foundation in identifying security issues and responding to potential threats in a structured manner.
